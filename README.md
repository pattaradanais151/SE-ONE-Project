## 📖 About The Project

**SE Portal Workspace** is a modern, fast, and secure web application designed specifically for Software Engineering students. It serves as a centralized hub for resource management, user authentication, and administrative controls with an intuitive, Apple-inspired glassmorphism UI.

### ✨ Key Features

- **🔐 Secure Authentication:** Seamless login/register system powered by Supabase Auth with automatic `@se-rmutl.com` email handling.
- **👥 Role-Based Access Control (RBAC):** Three distinct tiers of access (`User`, `Admin`, `Super Admin`) for granular permission management.
- **📂 Resource Center:** A centralized cloud storage system to upload, download, and manage study materials and assignments.
- **🛡️ Advanced Security:** Built-in Base64 file encoding to bypass storage naming restrictions and prevent Unicode errors.
- **💬 Discord Integration:** Automated webhook notifications for real-time activity tracking (User creations, File uploads/deletions, Account bans).
- **🌓 Dark/Light Mode:** Beautiful, responsive UI that adapts to your system preferences automatically.

## 🛠️ Built With

* **Frontend Framework:** [React 18](https://reactjs.org/) powered by [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Icons & Animations:** [Lucide React](https://lucide.dev/) & [Animate.css](https://animate.style/)
* **Backend as a Service (BaaS):** [Supabase](https://supabase.com/) (Auth, Database, Storage)
* **Notifications:** Discord Webhooks

* Node.js (v16.0.0 or higher)
